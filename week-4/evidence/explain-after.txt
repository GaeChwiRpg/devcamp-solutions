# EXPLAIN After — (status, created_at DESC) 복합 인덱스 추가 후

쿼리는 동일:
  SELECT * FROM products
  WHERE status = 'ACTIVE'
  ORDER BY created_at DESC
  LIMIT 20;

H2 EXPLAIN ANALYZE 출력 발췌:

  selectFromProducts:
    PUBLIC.IDX_PRODUCTS_STATUS_CREATED_AT
    /* range scan on (status, created_at DESC) */
    /* scanCount: 21 */
    /* limit hits index ordering */

핵심 신호:
- type: range scan (인덱스 사용)
- scanCount: 21 (LIMIT 20 + 살짝)
- 정렬 비용 0 (인덱스 정렬 그대로 사용)

남는 한계:
- searchByKeyword 의 `LOWER(title) LIKE '%kw%'` 는 인덱스 활용 불가.
  full text index 또는 트리그램 index 가 필요하지만 이번 주차 범위 밖.
- 학생은 이 한계도 evidence/latency-comparison.md 마지막 줄에 같이 적는다.
