## 이력서 변환 자산

- `resume-bullets-before.md` — 변경 전 bullet (막연 표현)
- `resume-bullets-after.md` — 변경 후 (문제→시도→결과 수치 구조)
- `metrics-source.md` — 수치 출처 (어느 미션, 어느 evidence)

## 책의 프레임 적용 자산

- `problem-solving-story.md` — 책 1·2장 "문제해결능력 보여주기" 1개 풀어쓰기 (면접 답변용)
- `numerization-pattern.md` — 책 4장 11절 수치화 패턴 적용 비교 표

## 작성 원칙

- "이력서를 썼다"가 아니라 **"수치 출처가 본인 evidence로 추적 가능한가"**
- after bullet은 모두 **문제 → 시도 → 결과 수치** 3 요소 포함
- 문제해결 서사는 1분/3분 답변 분량으로 단계별 작성
